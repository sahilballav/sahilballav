### 👋 About Me
I am an Information Technology engineering student at KIIT University specializing in backend architecture, cloud orchestration, and full-stack development. My engineering philosophy revolves around building resilient, high-availability enterprise systems and seamlessly integrating Agentic AI capabilities into modern applications.

* 🔭 **Currently Building:** OmniCart (Cloud-native e-commerce), Enterprise P2P Inventory Dashboards, and Kukurbazar.
* 🌱 **Currently Exploring:** Advanced cloud orchestration (Kubernetes/AWS EKS), intent-based networking, and Apache Kafka event streaming.
* 🧠 **Problem Solving:** Conquered 200+ DSA challenges on LeetCode using Java, C++, and Python to sharpen core logic.
* 👯 **Looking to Collaborate on:** Java 21 / Spring Boot microservices, RESTful API design, and open-source AI integrations.
* 🎧 **When I'm Not Coding:** You can find me optimizing workflows while listening to Punjabi pop and hip-hop.
